## Tech News Pulse
##  Project Overview

Tech News Pulse is a web-based news aggregator focused on delivering the latest updates in technology and startups. The application allows users to explore trending news, filter content by categories, search for specific topics, and save articles for later reading.

This project is designed to demonstrate core frontend development concepts such as API integration, dynamic UI rendering, state management, and user experience enhancements.

## Purpose

The main goal of this project is to:

Practice working with real-world APIs
Build a responsive and interactive web application
Implement features like search, filtering, and local storage
Enhance UI/UX with features like dark mode
##  Public API Used
News API: https://newsapi.org/

This API provides real-time news data from various sources, including technology and startup-related articles.
